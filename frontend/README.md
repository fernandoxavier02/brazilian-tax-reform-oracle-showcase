# Brazilian Tax Reform Oracle — Frontend

Interface Angular 17 (standalone) da vitrine do Oracle de Reforma Tributaria.
Dados 100% mock — sem backend.

## Como executar

```bash
cd frontend
npm install
npm start
```

Abra http://localhost:4200. A rota padrao redireciona para `/chat`.

## Build

```bash
npm run build
```

## Rotas

- `/chat` — Chat Inteligente
- `/dashboard` — Status de Indexacao
- `/reforma` — Visao Geral IBS / CBS / IS
- `/pipeline` — Fluxo RAG
- `/metricas` — Confianca e Metricas
- `/arquitetura` — Camadas da arquitetura
