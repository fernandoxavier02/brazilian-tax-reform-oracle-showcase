# Brazilian Tax Reform Oracle — Frontend

Dashboard dark navy (legal-tech) em Angular 17 + Tailwind 3.4, alinhado aos mockups de produção.

## Como rodar

```bash
cd frontend
npm install
npm start
```

Abre em `http://localhost:4200`. A home redireciona para `/reforma`.

## Rotas

| Rota | Página |
|------|--------|
| `/reforma` | Visão Geral da Reforma |
| `/indexacao` | Dashboard de Indexação |
| `/chat` | Chat Inteligente |
| `/metricas` | Métricas de Confiança |
| `/fontes` | Fontes Oficiais |
| `/exportacoes` | Exportações |
| `/configuracoes` | Configurações |

Dados 100% mock — sem API.
